# docs/presentation

Presentación para la sustentación: **15 min de exposición + 5 de preguntas**, plantilla SENA (PowerPoint).

## Diapositivas obligatorias
1. Nombre del proyecto e integrantes
2. Logo y slogan
3. Justificación y valor agregado
4. Objetivo general
5. Misión y visión
6. Competencia (3 principales)
7. Descripción del producto o servicio
8. Presupuesto (necesidades, inversión inicial, mano de obra, totales)
9. Análisis legal (tipo de empresa y normativa)
10. Impactos

## Recordatorios
- Asistir con uniforme; la inasistencia injustificada = **NO APROBADO**.
- Llevar **prototipo funcionando** (casilleros + ESP32).
