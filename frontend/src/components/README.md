# frontend/src/components

Componentes reutilizables.

- `ui/` — botones, inputs, modales, alertas.
- `calendar/` — calendario de casilleros (ocupado = rojo/gris, libre = verde).
- `locker/` — tarjeta de estado de casillero.
- `charts/` — gráficas de ocupación y reservas vencidas vs. reclamadas.
- `qr/` — muestra el QR/identificador del estudiante.
